<h1 align="center">Silant App Project</h1>
Этот проект представляет собой полноценное приложение с backend и frontend частью.

<h2 align="center">Установка backend</h2>

1. **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/NikitaTichonow/silant

2. **Перейдите в папку backend:**
    ```bash
    cd backend

3. **Установите виртульное окружение и активируйте виртуальную среду:**
     ```bash
    python -m venv venv
    venv\Scripts\activate
  
5. **Установите зависимости**
   ```bash
    pip install -r requirements.txt

6. **Запустите сервер backend:**
    ```bash
    python manage.py runserver
    
7. **Документация API доступна по адресу:**

    http://127.0.0.1:8000/swagger/

<h2 align="center">Установка Frontend</h2>

1. **Перейдите в папку frontend:**
    ```bash
    cd frontend

2. **Установите зависимости:**
     ```bash
    npm i

3. **Запустите frontend:**
     ```bash
    npm start

4. **Приложение будет доступно по адресу:**

    http://localhost:3000

5. **Для того чтобы авторизоваться за разных пользователей, надо ввести:**

    ```Имя пользователя   user  Пароль  user
    Имя пользователя   admin  Пароль  admin
